Go to the **New Query** tab to create a new query. Enter a query name, then
describe your cohort in the natural language search bar (for example, “adults
with asthma”). Select the correct concept if prompted.

The **Query Tree** and **Hierarchy** panel show the structure of your query.
Review it in the **Preview**.

Select **Run Query** to view anonymised cohort counts.
